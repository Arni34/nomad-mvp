# NOMAD — offline mesh-мессенджер (MVP)

Браузерный симулятор mesh-сети для мессенджера, который работает без интернета. Сайт — один статический файл `index.html`, без сборки и зависимостей.

## Что внутри

- **E2E-шифрование** на WebCrypto: ECDH P-256 → AES-GCM, сообщения подписываются ECDSA P-256.
- **TTL** ограничивает число пересылок, чтобы пакеты не ходили по сети бесконечно.
- **Дедупликация** по `message_id`: одно сообщение, пришедшее разными путями, принимается один раз.
- **Store-and-forward**: если получателя нет в сети, relay держит сообщение в очереди и доставляет его, когда связь появляется.
- Controlled flooding, ACK-подтверждения доставки, защита от replay, oversized-пакетов и подмены payload.
- Встроенные приёмочные тесты и стресс-тест (вкладка «Тесты»).

> ⚠️ Радиоканал эмулируется: связь между «телефонами» зависит от расстояния между ними на карте. Это **не настоящий Bluetooth**, а симуляция протокола в браузере.

## Запуск

Откройте `index.html` в браузере. Больше ничего не нужно.
