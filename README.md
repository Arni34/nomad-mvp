# NOMAD — мессенджер через спутник

Переписка через спутники Iridium там, где нет ни интернета, ни сотовой связи. Сообщения шифруются на устройстве и уходят через модем **RockBLOCK 9603** (Iridium SBD), подключённый к компьютеру по USB. Ни отправителю, ни получателю интернет не нужен.

Сайт статический, без сборки и зависимостей. После первой загрузки он кэшируется (service worker) и открывается офлайн.

## Два режима

| | Модем RockBLOCK | Демо |
|---|---|---|
| Что это | Настоящая спутниковая связь | Три виртуальных модема и симулятор сети Iridium |
| Что нужно | Модем RockBLOCK 9603/9602 у обоих собеседников, активная линия и кредиты Rock7, Chrome или Edge на компьютере (Web Serial) | Любой браузер |
| Где хранится профиль | В браузере (localStorage): ключи, контакты, переписка, очередь | В памяти вкладки |

В демо работает тот же драйвер модема и тот же мессенджер, что и с железом. Виртуальный модем отвечает на те же AT-команды, что и настоящий 9603, а заменяется только последовательный порт.

## Как идёт сообщение

```
модем A ──SBD──▶ спутник Iridium ──▶ шлюз ──▶ облако RockBLOCK (адрес RB<серийный B>)
                                                 │ очередь MT получателя
модем B ◀──SBD── спутник Iridium ◀── SBDRING ◀───┘
```

1. Отправитель шифрует текст и кладёт пакет в MO-буфер модема (`AT+SBDWB`), добавив адрес `RB` + 7 цифр серийного номера получателя.
2. Сеанс связи `AT+SBDIX` отправляет его на спутник, и облако RockBLOCK ставит его в очередь получателя.
3. Модем получателя получает `SBDRING` и забирает сообщение своим сеансом (`AT+SBDIXA` → `AT+SBDRB`).
4. Получатель расшифровывает сообщение и отправляет подтверждение доставки тем же путём (✓✓).

Если неба не видно, сообщение ждёт в очереди и уходит само, с паузами между попытками. Если получатель недоступен, сообщение ждёт его на шлюзе Iridium.

## Протокол

Один пакет укладывается в одно SBD-сообщение. Лимит модема 9603: 340 байт MO и 270 байт MT, поэтому пакет занимает не больше 270 байт.

```
[адрес RB 9] [версия|тип 1][флаги 1][id 8][отправитель 8][время 4] [IV 12] [шифротекст ≤220][тег GCM 16]
              \__________ заголовок 22 байта, защищён как AAD ______/
```

- Ключи: ECDH P-256 → HKDF-SHA256 → AES-256-GCM (WebCrypto). Секретный ключ не покидает устройство.
- Подменённый байт в любом месте пакета ломает GCM-тег, и получатель такой пакет отбрасывает.
- Текст сжимается (deflate-raw), только если это экономит байты. При распаковке стоит ограничение от zip-бомб.
- Повторный пакет показывается один раз (дедупликация по id). Пакеты от тех, кого нет в контактах, отбрасываются.
- Контакты добавляются кодом `nomad1.<серийный>.<публичный ключ>.<имя>`. Им нужно обменяться заранее, пока есть связь.

## Структура

```
index.html, styles.css    интерфейс
src/protocol.js           шифрование и формат пакета
src/sbd.js                AT-драйвер Iridium 9602/9603 + Web Serial
src/sim.js                симулятор сети Iridium и виртуальный модем
src/messenger.js          контакты, переписка, очередь, сеансы, подтверждения
src/app.js                экраны, панель неба, AT-консоль
sw.js                     офлайн-кэш
tests/                    тесты (node:test)
```

## Тесты

```bash
npm test
```

47 тестов на встроенном `node:test`, без зависимостей (нужен Node 20+). Что проверяется:
- шифрование, подмена и формат пакета;
- AT-драйвер: эхо, контрольные суммы, SBDRING посреди бинарного ответа, побайтовый приём, таймауты;
- сценарии целиком через симулятор: доставка с ✓✓, очередь без неба, store-and-forward на шлюзе, дубликаты, чужие и подделанные пакеты, сохранение после перезапуска, ноль сетевых запросов.

Тесты запускаются в GitHub Actions на каждый пуш.

## Локальный запуск

ES-модули не работают с `file://`, поэтому нужен любой статический сервер:

```bash
npm run serve
```

Затем откройте http://localhost:8080.

## Ограничения

- Модем RockBLOCK 9704 (протокол IMT/JSPR) пока не поддерживается.
- Web Serial есть только в Chrome и Edge на компьютере. На iPhone подключить модем нельзя, демо работает везде.
- Встроенная спутниковая связь iPhone и Android закрыта для сторонних приложений, поэтому нужен отдельный модем.
- Счётчик кредитов показывает оценку: 1 кредит RockBLOCK списывается за каждые начатые 50 байт.
